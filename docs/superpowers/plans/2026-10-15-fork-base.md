# Neverwas fork base — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the local clone of Bulk Crap Uninstaller v6.3 into the Neverwas fork: rebranded surface, no third-party network traffic, Windows CI, a Forgejo mirror, and an upstream-merge procedure that costs almost nothing.

**Architecture:** A light fork. Every branding change is data in `tools/rebrand-rules.psd1`, applied by an idempotent PowerShell module (`tools/Rebrand.psm1`) so that after an upstream merge the procedure is "take theirs, rerun the script". Real behavior changes (offline home-server client, update URL parsing) are small, unit-tested C# edits. CI on GitHub (`windows-2022`) enforces build, tests, brand check and an endpoint guard.

**Tech Stack:** C# / .NET 8 WinForms (`net8.0-windows10.0.18362.0`), MSTest 4.4, Visual Studio MSBuild (full framework — the solution has COM references, `dotnet build` fails with MSB4803), Windows PowerShell 5.1 + built-in Pester 3.4.0, GitHub Actions, `gh` CLI, Forgejo API.

**Spec:** `docs/superpowers/specs/2026-10-15-fork-base-design.md`

## Review Focus

1. **Base64 resources contain `BCU` by accident** (`/BCU+` inside image data) → the rebrand must not touch typed/binary `<data>` elements; a corrupted image breaks the form at runtime. Pinned in Task 2 ("leaves typed and binary resources untouched").
2. **Upstream rewrites a line a literal rule targets** → `rebrand.ps1` must fail loudly naming the file and rule, never silently skip. Pinned in Task 2 ("throws when neither text is present") and exercised end to end in Task 9.
3. **A rule whose replacement contains its own search text** → running the script twice would double-apply. Pinned in Task 3 (`RebrandRules.Tests.ps1`).
4. **Neverwas started next to a running BCU, or a portable folder that still has `BCUninstaller.settings`** → Neverwas must start, use `Neverwas.settings`, and not read the BCU file. Checked by hand in Task 3 step "smoke test".
5. **No Neverwas release exists yet** (the latest-release URL redirects to `/releases`, not `/releases/tag/vX`) → the update check must report "no info", not crash or offer a bogus update. Pinned in Task 5 (`ParseVersionFromReleaseUrl` returns null).

### Task 2: Rebrand engine (`tools/Rebrand.psm1`)

**Files:**
- Create: `tools/Rebrand.psm1`
- Test: `tools/Rebrand.Tests.ps1`

**Interfaces:**
- Produces:
  - `Read-TextFile -Path <string>` → `[pscustomobject]@{ Text = <string>; Encoding = <System.Text.UTF8Encoding> }` (BOM preserved through the encoding object; throws on UTF-16).
  - `Write-TextFile -Path <string> -Text <string> -Encoding <System.Text.Encoding>`
  - `Convert-ResxBrand -Text <string> -ValueRules <object[]>` → `<string>`. Each rule: `@{ Find = <string>; Replace = <string>; Regex = <bool> }`.
  - `Convert-LiteralRules -Text <string> -Rules <object[]> -File <string>` → `<string>`. Each rule: `@{ File = <string>; Find = <string>; Replace = <string> }`. Throws if neither `Find` nor `Replace` is present.
  - `Invoke-Rebrand -Root <string> -Rules <hashtable> [-Check]` → `string[]` of repo-relative paths (forward slashes) that changed (or would change with `-Check`). `Rules` has keys `Literal` (literal rules) and `ResxValue` (value rules). Literal rules run before resx rules on the same file.

Create `tools/Rebrand.psm1`:

```powershell
Set-StrictMode -Version 2.0

function Read-TextFile {
    param([Parameter(Mandatory = $true)][string]$Path)
    $bytes = [IO.File]::ReadAllBytes($Path)
    if ($bytes.Length -ge 2 -and (($bytes[0] -eq 0xFF -and $bytes[1] -eq 0xFE) -or ($bytes[0] -eq 0xFE -and $bytes[1] -eq 0xFF))) {
        throw "Rebrand does not support UTF-16 files: $Path"
    }
    $hasBom = $bytes.Length -ge 3 -and $bytes[0] -eq 0xEF -and $bytes[1] -eq 0xBB -and $bytes[2] -eq 0xBF
    $encoding = New-Object System.Text.UTF8Encoding($hasBom)
    $offset = 0
    if ($hasBom) { $offset = 3 }
    $text = $encoding.GetString($bytes, $offset, $bytes.Length - $offset)
    [pscustomobject]@{ Text = $text; Encoding = $encoding }
}

function Write-TextFile {
    param(
        [Parameter(Mandatory = $true)][string]$Path,
        [Parameter(Mandatory = $true)][AllowEmptyString()][string]$Text,
        [Parameter(Mandatory = $true)][System.Text.Encoding]$Encoding
    )
    [IO.File]::WriteAllText($Path, $Text, $Encoding)
}

function Convert-ResxBrand {
    param(
        [Parameter(Mandatory = $true)][AllowEmptyString()][string]$Text,
        [Parameter(Mandatory = $true)][AllowEmptyCollection()][object[]]$ValueRules
    )
    $dataEvaluator = {
        param($dataMatch)
        $attrs = $dataMatch.Groups['attrs'].Value
        # Typed and binary resources (images, icons, ResXFileRef) carry base64 or type names: never touch them.
        if ($attrs -cmatch '\s(type|mimetype)\s*=') { return $dataMatch.Value }
        $valueEvaluator = {
            param($valueMatch)
            $value = $valueMatch.Groups['v'].Value
            foreach ($rule in $ValueRules) {
                if ($rule.Regex) { $value = [regex]::Replace($value, $rule.Find, $rule.Replace) }
                else { $value = $value.Replace($rule.Find, $rule.Replace) }
            }
            '<value>' + $value + '</value>'
        }
        $body = [regex]::Replace($dataMatch.Groups['body'].Value, '(?s)<value>(?<v>.*?)</value>', $valueEvaluator)
        '<data' + $attrs + '>' + $body + '</data>'
    }
    # (?<!/) skips self-closing <data ... />, which would otherwise capture the next element's body.
    [regex]::Replace($Text, '(?s)<data\b(?<attrs>[^>]*)(?<!/)>(?<body>.*?)</data>', $dataEvaluator)
}

function Convert-LiteralRules {
    param(
        [Parameter(Mandatory = $true)][AllowEmptyString()][string]$Text,
        [Parameter(Mandatory = $true)][object[]]$Rules,
        [Parameter(Mandatory = $true)][string]$File
    )
    foreach ($rule in $Rules) {
        if ($Text.Contains($rule.Find)) {
            $Text = $Text.Replace($rule.Find, $rule.Replace)
        }
        elseif (-not $Text.Contains($rule.Replace)) {
            throw ("Rebrand rule broken in ${File}: neither '{0}' nor '{1}' was found. Upstream changed this line; update tools/rebrand-rules.psd1." -f $rule.Find, $rule.Replace)
        }
    }
    $Text
}

function Invoke-Rebrand {
    param(
        [Parameter(Mandatory = $true)][string]$Root,
        [Parameter(Mandatory = $true)][hashtable]$Rules,
        [switch]$Check
    )
    $Root = (Resolve-Path -LiteralPath $Root).Path.TrimEnd('\', '/')

    $literalByFile = @{}
    foreach ($rule in @($Rules.Literal)) {
        if (-not $literalByFile.ContainsKey($rule.File)) { $literalByFile[$rule.File] = @() }
        $literalByFile[$rule.File] += $rule
    }

    $files = @{}
    foreach ($rel in $literalByFile.Keys) { $files[$rel] = $true }
    $sourceDir = Join-Path $Root 'source'
    if (Test-Path -LiteralPath $sourceDir) {
        Get-ChildItem -LiteralPath $sourceDir -Recurse -Filter '*.resx' -File |
            Where-Object { $_.FullName -notmatch '[\\/](bin|obj)[\\/]' } |
            ForEach-Object { $files[$_.FullName.Substring($Root.Length + 1).Replace('\', '/')] = $true }
    }

    $changed = New-Object System.Collections.Generic.List[string]
    foreach ($rel in ($files.Keys | Sort-Object)) {
        $path = Join-Path $Root $rel
        if (-not (Test-Path -LiteralPath $path)) { throw "Rebrand rule points to missing file: $rel" }
        $file = Read-TextFile -Path $path
        $text = $file.Text
        if ($literalByFile.ContainsKey($rel)) { $text = Convert-LiteralRules -Text $text -Rules $literalByFile[$rel] -File $rel }
        if ($rel.EndsWith('.resx')) { $text = Convert-ResxBrand -Text $text -ValueRules @($Rules.ResxValue) }
        if ($text -cne $file.Text) {
            $changed.Add($rel)
            if (-not $Check) { Write-TextFile -Path $path -Text $text -Encoding $file.Encoding }
        }
    }
    , $changed.ToArray()
}

Export-ModuleMember -Function Read-TextFile, Write-TextFile, Convert-ResxBrand, Convert-LiteralRules, Invoke-Rebrand
```

```powershell
Set-StrictMode -Version 2.0

$script:Patterns = @('bugsklocman', 'klocmansoftware', 'Klocman/Bulk-Crap-Uninstaller', 'dappcdn')
$script:Extensions = @('.cs', '.resx', '.cpp', '.h', '.rc', '.csproj', '.vcxproj', '.props', '.targets', '.config', '.json', '.yml', '.yaml', '.bat')
$script:ExcludedDirs = @('.git', 'bin', 'obj', 'tools', 'docs', 'doc', 'installer')

function Find-ForbiddenEndpoint {
    param([Parameter(Mandatory = $true)][string]$Root)
    $Root = (Resolve-Path -LiteralPath $Root).Path.TrimEnd('\', '/')
    $hits = New-Object System.Collections.Generic.List[object]
    $files = Get-ChildItem -LiteralPath $Root -Recurse -File | Where-Object {
        $script:Extensions -contains $_.Extension.ToLowerInvariant() -and
        -not (($_.FullName.Substring($Root.Length + 1) -split '[\\/]' | Select-Object -SkipLast 1) | Where-Object { $script:ExcludedDirs -contains $_ })
    }
    foreach ($file in $files) {
        $lineNumber = 0
        foreach ($line in [IO.File]::ReadAllLines($file.FullName)) {
            $lineNumber++
            $trimmed = $line.TrimStart()
            if ($trimmed.StartsWith('//') -or $trimmed.StartsWith('*') -or $trimmed.StartsWith('/*') -or $trimmed.StartsWith('<!--')) { continue }
            foreach ($pattern in $script:Patterns) {
                if ($line.IndexOf($pattern, [StringComparison]::OrdinalIgnoreCase) -ge 0) {
                    $hits.Add([pscustomobject]@{ File = $file.FullName.Substring($Root.Length + 1).Replace('\', '/'); Line = $lineNumber; Text = $line.Trim() })
                    break
                }
            }
        }
    }
    , $hits.ToArray()
}
```

```powershell
<#
.SYNOPSIS
    Writes a provisional Neverwas icon (white "N" on a dark disc) as a multi-size .ico with PNG entries.
    Replaced by the real logo in the branding subproject.
#>
[CmdletBinding()]
param([Parameter(Mandatory = $true)][string]$Path)

$ErrorActionPreference = 'Stop'
Add-Type -AssemblyName System.Drawing

$sizes = @(16, 24, 32, 48, 64, 128, 256)
$images = New-Object System.Collections.Generic.List[byte[]]
foreach ($size in $sizes) {
    $bitmap = New-Object System.Drawing.Bitmap $size, $size
    $graphics = [System.Drawing.Graphics]::FromImage($bitmap)
    $graphics.SmoothingMode = [System.Drawing.Drawing2D.SmoothingMode]::AntiAlias
    $graphics.TextRenderingHint = [System.Drawing.Text.TextRenderingHint]::AntiAliasGridFit
    $graphics.Clear([System.Drawing.Color]::Transparent)
    $disc = New-Object System.Drawing.SolidBrush ([System.Drawing.Color]::FromArgb(255, 28, 30, 38))
    $graphics.FillEllipse($disc, 0, 0, $size - 1, $size - 1)
    $font = New-Object System.Drawing.Font 'Segoe UI', ([single]($size * 0.58)), ([System.Drawing.FontStyle]::Bold), ([System.Drawing.GraphicsUnit]::Pixel)
    $format = New-Object System.Drawing.StringFormat
    $format.Alignment = [System.Drawing.StringAlignment]::Center
    $format.LineAlignment = [System.Drawing.StringAlignment]::Center
    $graphics.DrawString('N', $font, [System.Drawing.Brushes]::White, (New-Object System.Drawing.RectangleF 0, 0, $size, $size), $format)
    $stream = New-Object System.IO.MemoryStream
    $bitmap.Save($stream, [System.Drawing.Imaging.ImageFormat]::Png)
    $images.Add($stream.ToArray())
    $font.Dispose(); $disc.Dispose(); $graphics.Dispose(); $bitmap.Dispose(); $stream.Dispose()
}

# ICO layout: ICONDIR (6 bytes) + one ICONDIRENTRY (16 bytes) per image + image data.
$output = New-Object System.IO.MemoryStream
$writer = New-Object System.IO.BinaryWriter $output
$writer.Write([UInt16]0); $writer.Write([UInt16]1); $writer.Write([UInt16]$sizes.Count)
$offset = 6 + 16 * $sizes.Count
for ($i = 0; $i -lt $sizes.Count; $i++) {
    $dimension = $sizes[$i]
    if ($dimension -ge 256) { $dimension = 0 }   # 0 means 256 in the ICO format
    $writer.Write([byte]$dimension); $writer.Write([byte]$dimension)
    $writer.Write([byte]0); $writer.Write([byte]0)
    $writer.Write([UInt16]1); $writer.Write([UInt16]32)
    $writer.Write([UInt32]$images[$i].Length); $writer.Write([UInt32]$offset)
    $offset += $images[$i].Length
}
foreach ($image in $images) { $writer.Write($image) }
$writer.Flush()
[System.IO.File]::WriteAllBytes($Path, $output.ToArray())
$writer.Dispose()
```
